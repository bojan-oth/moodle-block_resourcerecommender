# Testing

## Installation

- [ ] Moodle detects the plugin.
- [ ] Plugin installation finishes without errors.
- [ ] The block can be added to a course.

## Recommendation behavior

- [ ] Relevant resources are ranked above less relevant ones.
- [ ] No more than five recommendations are displayed.
- [ ] The currently viewed resource is excluded.
- [ ] Hidden or inaccessible resources are not recommended.
- [ ] A course with no suitable resources displays a friendly message.
- [ ] Resource links open the correct Moodle pages.

## Interface

- [ ] Titles and links are readable.
- [ ] The block fits a normal course page.
- [ ] The layout is usable on narrower screens.

## Regression

- [ ] Other Moodle course content continues to work normally.
- [ ] No unexpected PHP errors or warnings are produced.
