
# Installation

## Prerequisites

- A working Moodle test site.
- A Moodle version supported by this plugin.
- Access to the Moodle site's plugin directory or plugin installer.

## Installation steps

1. Confirm the Moodle version used by the development team.
2. Copy or install the plugin into the Moodle `blocks/resourcerecommender`
   directory.
3. Visit Site administration > Notifications.
4. Follow Moodle's plugin installation or upgrade instructions.
5. Open a course and add the Resource Recommender block.
6. Confirm that the block appears without errors.
